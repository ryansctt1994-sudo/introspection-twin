Use a response channel you control and name the evidence location. No person is
appointed independent by this document. Different agent names, fresh keys, another
process, another host, or the same owner's external scheduler do not establish
independence. Disclose shared principals and conflicts. A signature on an operator
declaration authenticates its signer; it does not establish that declaration's truth.

accepted this request, and no stranger-run result is included in the release.

adjudicator/key-custody limitations. A useful counterexample is welcome even if
